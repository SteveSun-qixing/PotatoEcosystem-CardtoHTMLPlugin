# 阶段1 - 项目初始化

## 目标

完成项目的基础结构搭建，配置开发环境，创建核心类型定义。

## 任务清单

### 1.1 TypeScript 配置

创建 tsconfig.json，配置严格模式、模块解析、输出目录等。创建 tsup.config.ts，配置构建选项。

### 1.2 开发工具配置

创建 .eslintrc.cjs，配置代码规范检查。创建 .prettierrc，配置代码格式化。

### 1.3 核心类型定义

创建 src/types/index.ts，定义插件使用的所有类型：
- CardData：解析后的卡片数据结构
- BaseCardConfig：基础卡片配置
- RendererCode：渲染代码结构
- ConversionOptions：转换选项
- ConversionResult：转换结果
- ProgressInfo：进度信息

### 1.4 插件入口

创建 src/index.ts，导出插件主类和类型定义。创建 src/plugin.ts，实现 ConverterPlugin 接口的基本框架。

### 1.5 初始提交

完成以上任务后，提交到 Git 仓库。

## 完成标准

- TypeScript 编译通过
- ESLint 检查通过
- 类型定义完整且有注释
- 插件框架可以正常导出
