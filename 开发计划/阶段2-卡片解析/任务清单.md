# 阶段2 - 卡片解析模块

## 目标

实现 CardParser 模块，能够解析 .card 文件和卡片数据，输出结构化的卡片信息。

## 任务清单

### 2.1 CardParser 类实现

创建 src/parser/card-parser.ts，实现卡片解析逻辑：
- parse(source) 方法：解析卡片文件或数据
- 调用 SDK 的 FileAPI 读取卡片内容
- 调用 Foundation 的 ZIPProcessor 解压文件
- 调用 Foundation 的 DataSerializer 解析 YAML

### 2.2 元数据解析

实现 parseMetadata 方法，解析 metadata.yaml：
- 提取卡片名称、版本、描述
- 提取创建时间、修改时间
- 提取主题配置、标签

### 2.3 结构解析

实现 parseStructure 方法，解析 structure.yaml：
- 提取基础卡片列表
- 提取卡片排列顺序
- 构建卡片层级关系

### 2.4 基础卡片配置解析

实现 parseBaseCards 方法，遍历 content 目录：
- 读取每个基础卡片的配置文件
- 提取卡片类型、配置数据
- 收集资源引用

### 2.5 单元测试

创建 tests/unit/parser.test.ts：
- 测试正常卡片的解析
- 测试格式错误的处理
- 测试缺失文件的处理

### 2.6 提交

完成测试后提交到 Git 仓库。

## 完成标准

- 能正确解析标准格式的卡片文件
- 格式错误时返回明确的错误信息
- 单元测试覆盖率 >= 85%
