# 阶段5 - 主题处理模块

## 目标

实现 ThemeProcessor 模块，能够获取主题样式并应用到生成的 HTML 中。

## 任务清单

### 5.1 ThemeProcessor 类实现

创建 src/theme/theme-processor.ts，实现主题处理逻辑：
- process(themeId, htmlFiles) 方法：处理主题
- fetchTheme(themeId) 方法：获取主题样式
- generateThemeCSS(theme) 方法：生成 theme.css

### 5.2 主题样式提取

实现主题样式提取：
- 调用 SDK 的 ThemeManager 获取主题
- 提取 CSS 变量定义
- 提取组件样式规则
- 合并为完整的 CSS 文件

### 5.3 默认主题

实现默认主题处理：
- 当指定主题不存在时使用默认主题
- 当未配置主题时使用默认主题
- 默认主题提供基本的视觉效果

### 5.4 HTML 更新

实现 HTML 文件更新：
- 在所有 HTML 中添加 theme.css 引用
- 确保引用路径正确
- 主入口和基础卡片都需要引用

### 5.5 单元测试

创建 tests/unit/theme-processor.test.ts：
- 测试主题获取和处理
- 测试默认主题回退
- 测试 CSS 生成正确性

### 5.6 提交

完成测试后提交到 Git 仓库。

## 完成标准

- 能正确获取和应用主题
- 默认主题回退机制正常工作
- 单元测试覆盖率 >= 85%
