# 阶段3 - 渲染代码获取模块

## 目标

实现 RendererFetcher 模块，能够从基础卡片插件获取各类型卡片的前端渲染代码。

## 任务清单

### 3.1 RendererFetcher 类实现

创建 src/renderer/renderer-fetcher.ts，实现渲染代码获取逻辑：
- fetchRenderers(cardTypes) 方法：批量获取渲染代码
- fetchRenderer(cardType) 方法：获取单个类型的渲染代码
- 调用 SDK 的 PluginManager 查询插件

### 3.2 渲染代码缓存

实现渲染代码缓存机制：
- 同一类型只获取一次
- 缓存在内存中复用
- 支持清除缓存

### 3.3 占位渲染器

实现 getPlaceholderRenderer 方法：
- 当插件不存在时返回占位 HTML
- 显示卡片类型和提示信息
- 样式简洁明了

### 3.4 单元测试

创建 tests/unit/renderer-fetcher.test.ts：
- 测试正常获取渲染代码
- 测试插件不存在的处理
- 测试缓存机制

### 3.5 提交

完成测试后提交到 Git 仓库。

## 完成标准

- 能正确获取已安装插件的渲染代码
- 插件不存在时返回合理的占位内容
- 单元测试覆盖率 >= 85%
