# 阶段4 - HTML 生成模块

## 目标

实现 HTMLGenerator 模块，能够生成基础卡片的 HTML 文件和主入口页面。

## 任务清单

### 4.1 HTMLGenerator 类实现

创建 src/generator/html-generator.ts，实现 HTML 生成逻辑：
- generate(cardData, renderers) 方法：生成所有 HTML
- generateBaseCardHTML(baseCard, renderer) 方法：生成单个基础卡片的 HTML
- generateIndexHTML(cardData, baseCardIds) 方法：生成主入口页面

### 4.2 基础卡片 HTML 模板

实现基础卡片的 HTML 模板：
- 完整的 HTML5 结构
- 引入必要的样式和脚本
- 注入卡片配置数据
- 调用渲染代码渲染内容

### 4.3 主入口页面模板

实现主入口页面的 HTML 模板：
- 页面框架结构
- 卡片容器布局
- iframe 嵌套各基础卡片
- 引入主题样式

### 4.4 数据注入

实现配置数据注入机制：
- 将卡片配置序列化为 JSON
- 安全地嵌入到 HTML 中
- 供渲染代码读取使用

### 4.5 单元测试

创建 tests/unit/html-generator.test.ts：
- 测试基础卡片 HTML 生成
- 测试主入口页面生成
- 测试数据注入的正确性

### 4.6 提交

完成测试后提交到 Git 仓库。

## 完成标准

- 生成的 HTML 结构正确
- 数据注入安全且正确
- 单元测试覆盖率 >= 85%
