# 阶段6 - 资源处理模块

## 目标

实现 ResourceHandler 模块，能够处理卡片中的资源文件并更新 HTML 中的引用。

## 任务清单

### 6.1 ResourceHandler 类实现

创建 src/resource/resource-handler.ts，实现资源处理逻辑：
- handle(htmlFiles, resources, strategy) 方法：处理所有资源
- processResource(resource, strategy) 方法：处理单个资源
- updateReferences(htmlFiles, resourceMap) 方法：更新引用

### 6.2 资源扫描

实现资源引用扫描：
- 解析 HTML 中的资源引用（img src、video src 等）
- 解析 CSS 中的资源引用（url()）
- 收集所有唯一的资源路径

### 6.3 资源处理策略

实现不同的资源处理策略：
- copy-all：复制所有资源
- copy-local：复制本地资源，保留网络引用
- embed：将资源嵌入为 base64
- reference-only：只更新引用路径，不复制

### 6.4 路径处理

实现资源路径处理：
- 将原始路径映射到输出路径
- 按资源类型组织目录（images、videos 等）
- 处理路径冲突（重名文件）

### 6.5 HTML 引用更新

实现 HTML 中资源引用的更新：
- 替换为相对于输出目录的路径
- 确保路径在不同位置都能正确解析
- 处理 CSS 中的 url() 引用

### 6.6 单元测试

创建 tests/unit/resource-handler.test.ts：
- 测试资源扫描
- 测试各种处理策略
- 测试路径更新正确性

### 6.7 提交

完成测试后提交到 Git 仓库。

## 完成标准

- 资源扫描完整准确
- 各种策略正确实现
- 路径更新后资源可以正常加载
- 单元测试覆盖率 >= 85%
