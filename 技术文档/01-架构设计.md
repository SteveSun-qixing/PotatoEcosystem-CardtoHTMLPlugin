# CardtoHTMLPlugin 架构设计文档

## 整体架构

CardtoHTMLPlugin 采用模块化架构，将转换过程分解为多个独立的处理阶段。每个阶段由专门的处理器负责，处理器之间通过数据传递协作。

转换流程分为五个阶段：卡片解析、渲染代码获取、HTML 生成、主题处理、资源处理。每个阶段的处理器可以独立测试和维护，也可以根据需要替换实现。

## 模块结构

插件包含以下核心模块。

CardParser 模块负责解析卡片文件。接收卡片路径或数据，解压卡片文件（如果是 .card 文件），读取 metadata.yaml 和 structure.yaml，验证格式正确性，输出结构化的卡片数据对象。

RendererFetcher 模块负责获取基础卡片的渲染代码。根据基础卡片的类型，通过 SDK 的插件 API 查询对应的渲染插件，获取该类型卡片的前端渲染代码（HTML 模板、CSS 样式、必要的 JavaScript）。

HTMLGenerator 模块负责生成 HTML 文件。接收卡片数据和渲染代码，为每个基础卡片生成独立的 HTML 文件，生成主入口 index.html 文件，组织 iframe 嵌套结构。

ThemeProcessor 模块负责处理主题。读取卡片的主题配置，通过 SDK 的主题 API 获取主题样式，提取 CSS 变量和样式规则，生成 theme.css 文件。

ResourceHandler 模块负责处理资源文件。扫描卡片中的资源引用，根据处理策略复制或下载资源文件，更新 HTML 中的资源引用路径，组织 assets 目录结构。

OutputWriter 模块负责输出结果。将生成的所有文件写入指定目录，或打包为数据结构返回。处理文件冲突，确保输出目录结构正确。

## 数据流

转换开始时，CardParser 接收输入，解析卡片数据。解析结果传递给 RendererFetcher，获取所有基础卡片类型的渲染代码。

卡片数据和渲染代码一起传递给 HTMLGenerator。HTMLGenerator 遍历每个基础卡片，将卡片配置数据注入渲染代码模板，生成 HTML 内容。同时生成主入口页面的 HTML。

HTMLGenerator 的输出传递给 ThemeProcessor。ThemeProcessor 读取主题配置，获取主题样式，生成 theme.css，并在所有 HTML 文件中添加主题引用。

处理后的 HTML 传递给 ResourceHandler。ResourceHandler 扫描所有 HTML 中的资源引用，处理资源文件，更新引用路径。

最终所有生成的内容传递给 OutputWriter，写入输出目录或返回数据。

## 与外部系统的交互

插件通过薯片 SDK 与其他系统交互，所有调用都经过微内核路由。

与公共基础层的交互：调用 ZIPProcessor 解压 .card 文件，调用 DataSerializer 解析 YAML 配置文件，调用 FileConverter 注册自己。

与插件系统的交互：通过 PluginManager 查询已安装的基础卡片插件，获取各类型卡片的渲染代码。

与主题系统的交互：通过 ThemeManager 获取指定主题的样式定义，获取默认主题。

## 插件生命周期

插件加载时，初始化各个处理模块，向 FileConverter 注册转换能力。注册时声明支持 .card 到 HTML 的转换。

收到转换请求时，创建转换任务，按顺序执行各处理阶段。支持同时处理多个转换任务，每个任务独立运行。

插件卸载时，向 FileConverter 注销自己，清理资源。

## 错误处理策略

采用分层错误处理。每个处理模块捕获自己的错误，将错误信息包装为标准格式向上传递。顶层汇总所有错误，决定是中止还是继续。

可恢复错误（如单个基础卡片渲染失败）记录日志，生成占位内容，继续处理。不可恢复错误（如卡片格式完全无效）立即中止，返回错误结果。

所有错误都有唯一的错误码，格式为 CONV-HTML-XXX。错误信息包含上下文，如文件路径、卡片 ID、具体原因。

## 配置管理

插件的默认配置通过配置文件定义，运行时可以通过转换选项覆盖。

默认配置包括：是否包含资源（默认 true）、资源处理策略（默认复制本地、保留网络）、输出格式（默认目录）、并行处理数量（默认 4）。

转换选项可以覆盖任何默认配置，也可以添加额外的选项如自定义主题、输出路径等。

## 测试策略

单元测试覆盖每个处理模块。使用模拟数据测试 CardParser 的解析逻辑、HTMLGenerator 的生成逻辑、ResourceHandler 的路径处理等。

集成测试验证完整的转换流程。使用真实的卡片文件，验证输出结果的正确性，包括 HTML 结构、资源引用、主题应用。

性能测试验证大型卡片的处理效率。测试包含大量基础卡片和资源的卡片，确保内存占用和处理时间在合理范围内。
