# CardtoHTMLPlugin 接口定义文档

## 插件接口

CardtoHTMLPlugin 实现标准的转换器插件接口 ConverterPlugin，向公共基础层的 FileConverter 模块注册。

插件元数据包括唯一标识 cardto-html-plugin，显示名称"卡片转 HTML 插件"，当前版本号，支持的源文件类型数组（包含 .card），目标文件类型 html-directory，以及插件描述信息。

## 转换方法

核心转换方法接收两个参数：转换源和转换选项。

转换源描述要转换的卡片。类型字段指示是文件路径还是数据，path 字段存储文件路径，data 字段存储已解包的卡片数据，fileType 字段固定为 card。

转换选项控制转换行为。outputPath 指定输出目录路径，不指定则返回数据。includeAssets 控制是否包含资源文件。themeId 指定使用的主题，不指定则使用卡片配置或默认主题。assetStrategy 指定资源处理策略。parallelCount 指定并行处理数量。

## 转换结果

转换方法返回转换结果对象。success 字段指示是否成功。taskId 是此次转换的唯一标识。outputPath 是输出目录路径（如果指定了输出路径）。data 是输出数据（如果没有指定输出路径），包含所有生成文件的内容。error 是错误信息（如果失败）。warnings 是警告信息数组（如果有非致命问题）。stats 是转换统计信息，包含耗时、输入大小、输出大小、基础卡片数量、资源文件数量。

## 输出数据结构

当不指定输出路径时，返回的 data 字段包含完整的输出内容。

顶层是一个文件映射，键是相对路径，值是文件内容。index.html 对应主入口页面的 HTML 字符串。theme.css 对应主题样式的 CSS 字符串。cards 目录下每个基础卡片一个 HTML 文件，键格式为 cards/{cardId}.html。assets 目录下是资源文件，键格式为 assets/{type}/{filename}，值是二进制数据。

## 默认选项方法

getDefaultOptions 方法返回插件的默认转换选项。默认包含资源文件，使用 copy-local 资源策略（复制本地资源，保留网络引用），并行处理数量为 4。

## 选项验证方法

validateOptions 方法验证转换选项的有效性。返回验证结果，包含是否有效、错误列表、警告列表。

验证规则包括：outputPath 如果指定必须是有效路径，assetStrategy 必须是支持的值之一，parallelCount 必须是正整数且不超过最大值。

## 进度回调接口

转换选项中可以包含 onProgress 回调函数，用于接收转换进度。

进度信息包含 taskId（任务标识）、status（状态：pending/parsing/rendering/processing/writing/completed/failed）、percent（完成百分比 0-100）、currentStep（当前步骤描述，如"正在渲染基础卡片 3/10"）。

## 内部模块接口

CardParser 模块的 parse 方法接收输入源（路径或数据），返回解析后的卡片数据对象。卡片数据对象包含 metadata（元数据对象）、structure（结构定义对象）、baseCards（基础卡片配置数组）、resources（资源引用列表）。

RendererFetcher 模块的 fetchRenderers 方法接收基础卡片类型列表，返回类型到渲染代码的映射。渲染代码对象包含 html（HTML 模板字符串）、css（样式字符串）、js（可选的脚本字符串）。

HTMLGenerator 模块的 generate 方法接收卡片数据和渲染代码映射，返回生成的 HTML 文件映射。

ThemeProcessor 模块的 process 方法接收主题 ID 和 HTML 文件映射，返回添加主题后的文件映射以及 theme.css 内容。

ResourceHandler 模块的 handle 方法接收 HTML 文件映射、资源列表和处理策略，返回处理后的 HTML 文件映射和资源文件映射。

OutputWriter 模块的 write 方法接收所有文件映射和输出路径，写入文件系统。如果不指定路径，返回数据结构。

## 错误码定义

插件定义以下错误码。

CONV-HTML-001 表示卡片文件不存在。CONV-HTML-002 表示卡片格式无效，无法解析。CONV-HTML-003 表示 metadata.yaml 缺失或格式错误。CONV-HTML-004 表示 structure.yaml 缺失或格式错误。CONV-HTML-005 表示基础卡片配置文件缺失。CONV-HTML-006 表示渲染插件不存在。CONV-HTML-007 表示渲染失败。CONV-HTML-008 表示主题不存在。CONV-HTML-009 表示资源文件缺失。CONV-HTML-010 表示资源处理失败。CONV-HTML-011 表示输出目录创建失败。CONV-HTML-012 表示文件写入失败。CONV-HTML-013 表示转换被取消。
