# CardtoHTMLPlugin 接口需求

**版本**: 1.0.0  
**日期**: 2026-02-03  
**状态**: 正式版

---

## 插件注册接口

CardtoHTMLPlugin 作为转换插件，需要向文件转换接口模块注册自己的转换能力。注册信息包括插件支持的源文件类型和目标文件类型。CardtoHTMLPlugin 的源文件类型是 card，目标文件类型是 html-directory（HTML 目录）。

注册接口还需要声明插件的版本信息、支持的转换选项、转换能力描述等元数据。文件转换接口模块使用这些信息建立路由映射，在收到转换请求时能够找到正确的插件。

插件启动时自动向微内核注册，注册成功后对外可用。插件卸载或停止时向接口模块注销，移除自己的转换能力记录。

## 转换请求接口

应用层通过 SDK 发起转换请求，请求最终路由到 CardtoHTMLPlugin。转换请求包含源文件路径、输出路径、转换选项三个主要部分。

源文件路径指向要转换的 .card 文件。路径可以是绝对路径，也可以是相对于工作区的相对路径。SDK 会验证路径的有效性，确保文件存在且是有效的卡片文件。

输出路径指定转换结果保存的目录。如果目录不存在，插件会创建它。如果目录已存在且不为空，根据转换选项决定是报错还是覆盖。

转换选项是一个配置对象，包含所有可调整的转换参数。选项的每个字段都有默认值，调用方只需要指定需要改变的选项。

## 转换选项接口

资源处理选项控制外部资源的处理方式。embedResources 字段指定是否下载并嵌入外部资源，默认值为 false。downloadTimeout 字段指定下载外部资源的超时时间，默认值为 30 秒。skipMissingResources 字段指定遇到无法获取的资源时是否跳过继续，默认值为 true。

输出格式选项控制生成的 HTML 的格式。minify 字段指定是否压缩输出的 HTML 和 CSS，默认值为 false。includeSourceMaps 字段指定是否生成源映射文件，默认值为 false。

元数据选项控制卡片元数据的处理。preserveMetadata 字段指定是否在输出中保留元数据，默认值为 true。metadataFormat 字段指定元数据的格式，可选 comment（HTML 注释）或 meta（meta 标签），默认值为 meta。

覆盖选项控制输出目录已存在时的行为。overwrite 字段指定是否覆盖已存在的文件，默认值为 false。cleanOutput 字段指定是否在转换前清空输出目录，默认值为 false。

## 转换结果接口

转换完成后，插件返回转换结果对象。结果对象包含状态、输出信息、统计信息、问题列表四个部分。

状态字段表示转换是否成功。可能的值包括 success（完全成功）、partial（部分成功，有警告）、failed（失败）。只有 success 和 partial 状态的结果可以使用。

输出信息包含输出目录路径、主入口文件路径、生成的文件总数、输出目录的总大小。这些信息帮助调用方了解转换产出的规模。

统计信息包含转换过程的详细计数。处理的基础卡片数量、复制的资源文件数量、下载的外部资源数量、应用的主题数量等。这些信息帮助调用方了解转换的完整性。

问题列表记录转换过程中遇到的警告和错误。每个问题项包含级别（warning 或 error）、代码、消息、相关文件路径。调用方可以根据问题列表判断转换质量。

## 进度回调接口

转换请求可以携带进度回调函数，插件在转换过程中定期调用这个函数报告进度。回调函数接收一个进度对象作为参数。

进度对象包含当前阶段、完成百分比、当前处理的项目、预计剩余时间。阶段值包括 parsing（解析卡片）、generating（生成页面）、copying（复制资源）、finalizing（最终处理）。

百分比是 0 到 100 之间的数值，表示整体完成进度。当前处理的项目是一个字符串，描述当前正在处理的文件或操作。预计剩余时间是一个毫秒数值，基于已完成工作量估算。

进度回调的调用频率由插件控制。插件确保在每个重要节点都会调用，但不会过于频繁以免影响性能。调用方不应该依赖特定的调用频率。

## 取消接口

长时间运行的转换任务支持取消。调用方在发起转换请求时获得一个任务 ID，可以使用这个 ID 请求取消任务。

取消请求发送后，插件在安全的时间点停止处理。插件不会立即终止，而是完成当前正在进行的原子操作后停止。这确保不会留下损坏的中间文件。

取消成功后，插件清理已生成的部分输出，返回 cancelled 状态的结果。调用方可以选择重新发起转换或放弃。

如果转换已经完成，取消请求无效，返回已完成的转换结果。如果转换已经失败，取消请求也无效，返回失败的结果。

## 内核服务调用接口

CardtoHTMLPlugin 需要调用薯片内核的多个服务来完成转换工作。所有服务调用都通过内核的路由系统进行。

文件服务用于读取卡片文件和写入输出文件。插件调用文件服务读取 .card 压缩包的内容，解析内部的配置文件和资源清单。写入输出时调用文件服务创建目录和保存文件。

插件服务用于获取基础卡片插件的信息。插件调用插件服务查询特定卡片类型对应的插件，获取插件的前端渲染代码。如果某个卡片类型没有对应的插件，记录警告并使用默认渲染。

主题服务用于获取主题包的样式定义。插件调用主题服务加载卡片配置中指定的主题，提取 CSS 变量和组件样式。如果主题不存在，使用默认主题。

资源服务用于解析和获取资源。对于卡片内部资源，通过资源服务获取资源数据。对于外部资源（如果启用了嵌入选项），通过资源服务下载远程文件。

## 错误码接口

插件定义了一系列错误码用于标识不同类型的错误。调用方可以根据错误码进行分类处理或显示对应的错误消息。

卡片相关错误使用 CARD 前缀。CARD-1001 表示卡片文件不存在。CARD-1002 表示卡片文件格式无效。CARD-1003 表示卡片结构文件缺失。CARD-1004 表示卡片元数据解析失败。

生成相关错误使用 GEN 前缀。GEN-2001 表示无法创建输出目录。GEN-2002 表示写入文件失败。GEN-2003 表示找不到基础卡片插件。GEN-2004 表示主题加载失败。

资源相关错误使用 RES 前缀。RES-3001 表示资源文件缺失。RES-3002 表示外部资源下载失败。RES-3003 表示资源文件复制失败。

运行时错误使用 RT 前缀。RT-4001 表示转换超时。RT-4002 表示内存不足。RT-4003 表示任务被取消。

## 日志接口

插件通过内核的日志服务记录运行信息。日志分为 debug、info、warn、error 四个级别。

debug 级别记录详细的执行步骤，如开始处理某个文件、完成某个阶段。这些日志在正常运行时不显示，调试时可以开启。

info 级别记录重要的执行节点，如开始转换、完成转换、生成的文件数量。这些信息帮助用户了解转换的整体过程。

warn 级别记录非致命的问题，如某个资源无法获取但使用了占位符继续。这些警告不影响转换完成，但可能影响输出质量。

error 级别记录致命错误，如卡片文件损坏导致无法继续。这些错误会导致转换失败。

## 版本兼容接口

插件声明支持的卡片格式版本范围。当处理的卡片版本在支持范围内时正常转换，版本过高或过低时返回版本不兼容的错误。

插件也声明支持的内核协议版本。内核加载插件时检查协议版本，版本不匹配时拒绝加载。这确保插件和内核之间的接口兼容。

版本信息在插件的清单文件中声明，内核在注册插件时读取并记录。调用方可以查询插件的版本信息，了解当前安装的插件版本及其兼容性范围。
